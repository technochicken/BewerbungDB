{# GET /api/v1/jobs #}
{{ badge('GET') }} /api/v1/jobs Alle Stellen abrufen Ausprobieren ↗

Gibt ein JSON-Array aller Stellen zurück. Unterstützt Filterung, Suche und Sortierung.

Parameter Beispiel Beschreibung
statusapplied,interviewKommagetrennte Status-Werte. Werte: new, reviewing, applied, interview, offer, accepted, rejected, closed, irrelevant
sourcearbeitsagenturQuelle filtern: arbeitsagentur oder manual
tagpythonNur Stellen mit diesem Tag
searchBackend MünchenVolltext-Suche in Titel, Firma, Ort, Beschreibung
sortchanged_desccreated_desc · created_asc · changed_desc · title_asc · company_asc · status · expires_asc
limit100Max. Einträge (Standard: 500, Max: 2000)
offset500Offset für Paginierung

{# GET /api/v1/jobs/{id} #}
{{ badge('GET') }} /api/v1/jobs/{id} Einzelne Stelle abrufen

Gibt alle Felder der Stelle zurück inklusive Tags-Array und alle Kontakt-/Bewerbungsfelder. Gibt 404 zurück wenn nicht gefunden.

{# PATCH /api/v1/jobs/{id} #}
{{ badge('PATCH') }} /api/v1/jobs/{id} Stelle aktualisieren (partiell)

Aktualisiert beliebige Felder einer Stelle. Nur gesendete Felder werden geändert — nicht gesendete bleiben unverändert. Jede Änderung wird im Verlauf protokolliert. Gibt {"status": "updated"} zurück. 

PATCH /api/v1/jobs/a3f9c21b7e
Content-Type: application/json

{
  // Nur zu ändernde Felder senden — alle anderen bleiben unverändert

  // Basisdaten
  "title": "...",
  "company": "...",
  "location": "...",
  "status": "applied",         // new|reviewing|applied|interview|offer|accepted|rejected|closed|irrelevant
  "job_type": "...",
  "salary": "...",
  "expires_at": "2026-09-01",
  "tags": ["python", "remote"],

  // Links & Monitoring
  "url": "...",
  "check_url": "...",
  "check_keyword": "...",

  // Inhalte
  "description": "...",
  "requirements": "...",
  "notes": "...",
  "html_content": "...",
  "external_id": "...",

  // Kontakt (Ansprechpartner)
  "contact_salutation": "Frau",      // Frau|Herr|""
  "contact_title": "Dr.",            // Dr.|Prof.|Prof. Dr.|""
  "contact_first_name": "...",
  "contact_last_name": "...",
  "contact_email": "...",
  "contact_street": "...",
  "contact_street_nr": "...",
  "contact_plz": "...",
  "contact_city": "...",

  // Bewerbungsdaten
  "job_name_personalized": "...",    // personalisierte Berufsbezeichnung für Anschreiben
  "company_floskel": "...",          // z.B. "bei der XYZ GmbH"
  "application_date": "2026-06-10", // ISO-Datum YYYY-MM-DD
  "bewerbungstext": "..."            // Freitext Anschreiben
}
Tipp für automatische Tools: Sende nur die Felder die geändert werden sollen. Ein PATCH mit nur {"bewerbungstext": "...", "application_date": "2026-06-10"} ändert ausschließlich diese beiden Felder.

Prüft die hinterlegte Monitoring-URL sofort. Setzt Status auf closed bei HTTP 404/410 oder fehlendem Keyword. Kein Request-Body nötig.

Verwaltung der automatischen Suchkonfigurationen (Arbeitsagentur-API-Suchen). Basis: {{ base_url }}/api/v1/searches

{# GET /api/v1/searches #}
{{ badge('GET') }} /api/v1/searches Alle Suchkonfigurationen Ausprobieren ↗

Array aller gespeicherten Suchkonfigurationen inkl. tags und match_words als Arrays.

{# POST /api/v1/searches #}
{{ badge('POST') }} /api/v1/searches Suchkonfiguration anlegen 
{
  "name": "Python Jobs München",   // required
  "keywords": "Python Entwickler", // required
  "location": "München",
  "radius": 30,                    // km, default 30
  "angebotsart": 1,                // 1=Arbeit, 4=Ausbildung, 34=Praktikum
  "arbeitszeit": "vz",             // vz=Vollzeit, tz=Teilzeit (optional)
  "tags": ["python", "backend"],   // automatisch zu neuen Stellen hinzugefügt
  "match_words": ["Python"],       // Stelle wird nur gespeichert wenn ein Wort im Titel vorkommt
  "poll_interval": 3600,           // Sekunden zwischen Polls (für Info, global konfigurierbar)
  "active": true
}
{# GET /api/v1/searches/{id} #}
{{ badge('GET') }} /api/v1/searches/{id} Einzelne Suchkonfiguration

Gibt eine Suchkonfiguration zurück. Enthält auch last_polled_at und total_found.

{# PATCH /api/v1/searches/{id} #}
{{ badge('PATCH') }} /api/v1/searches/{id} Suchkonfiguration aktualisieren

Partielles Update. Felder: name, keywords, location, radius, tags, match_words, active, poll_interval, angebotsart, arbeitszeit.

{# DELETE /api/v1/searches/{id} #}
{{ badge('DELETE') }} /api/v1/searches/{id} Suchkonfiguration löschen

Löscht die Suchkonfiguration. HTTP 204 (kein Body). Gefundene Stellen bleiben erhalten.

{# POST /api/v1/searches/{id}/poll #}
{{ badge('POST') }} /api/v1/searches/{id}/poll Sofortiger Poll auslösen

Startet einen Arbeitsagentur-Suchlauf sofort. Gibt zurück: {"new": 3, "total": 150, "filtered": 42}

Kein Request-Body nötig.

{# end searches section #} {# ══════════════════════ IMPORT SECTION ══════════════════════ #}

Web-Endpunkte zum Importieren von Stellen via JSON — entweder als eingefügten Text oder als hochgeladene Datei. Erreichbar unter /import (Browser) oder direkt per POST. Authentifizierung: Session-Cookie (eingeloggt sein).

{# POST /import — paste #}
{{ badge('POST') }} /import Stelle aus eingefügtem JSON anlegen Zur Import-Seite ↗

Legt eine neue Stelle anhand eines JSON-Texts an und leitet direkt auf die neue Stelle weiter. Content-Type: application/x-www-form-urlencoded

Formularfeld Beschreibung
import_modeMuss paste sein
json_textJSON-String mit den Stellendaten (mind. title erforderlich)
 
curl -b "bwdb_session=..." -X POST {{ base_url }}/import \
  -d "import_mode=paste" \
  --data-urlencode 'json_text={"title":"Backend Dev","company":"ABC GmbH","status":"new"}'
{# POST /import — file upload #}
{{ badge('POST') }} /import Stelle aus JSON-Datei anlegen

Wie oben, aber als Datei-Upload. Content-Type: multipart/form-data

Formularfeld Beschreibung
import_modeMuss file sein
json_file.json-Datei (max. 1 MB, UTF-8)
 
curl -b "bwdb_session=..." -X POST {{ base_url }}/import \
  -F "import_mode=file" \
  -F "json_file=@stelle.json"

Excel – Power Query Einrichtung

Mit Power Query kann Excel alle Stellen-Daten direkt aus der API laden und auf Knopfdruck aktualisieren.

  1. 1

    Excel öffnen → Reiter "Daten"

    Klicke auf Daten abrufen → Aus anderen Quellen → Aus dem Web

  2. 2

    URL eingeben

    {{ base_url }}/api/v1/jobs

    Tipp: Filter anhängen, z.B. ?status=applied,interview,offer für aktive Bewerbungen

  3. 3

    Power Query-Editor: Liste in Tabelle umwandeln

    Es erscheint eine List. Klicke auf In Tabelle konvertieren (oben links) → OK. Dann auf den Spalten-Expand-Button ⇔ → gewünschte Felder auswählen → OK.

  4. 4

    Schließen & laden

    Klicke auf Schließen & laden. Die Daten erscheinen als Tabelle.

  5. ✓

    Daten aktualisieren

    Daten → Alle aktualisieren oder Rechtsklick auf die Tabelle → Aktualisieren.

Hinweis: BewerbungsDB muss laufen während Excel lädt. Starte mit python run.py bevor du in Excel aktualisierst.
